One list, two verbs

the proposed picker

Today these three live in a menu with no search, and every branch in the project is in it. A menu you have to scroll is a menu you give up on, which is how you end up cutting a new branch when you meant to open one. A search field and a plain verb on every row fixes both.

search

One field over everything. Branch names, pull request titles, numbers and authors. Paste a pull request URL and the row for it appears, including the closed ones and the ones raised against a fork that the list itself does not offer.

verb

The same branch can appear twice, under two headings. That is the point. Open puts you on the branch itself; New branch from cuts a fresh one off its tip. The two sit one above the other so the choice is made with both in view, rather than discovered a day later in an empty Changes tab.

in use

A branch already open stays on the list. Git will not put one branch in two worktrees, so today Bloom quietly drops it, and the branch you are hunting for is simply not there. Better to show it, name the workspace holding it, and let the row take you straight to that workspace.

keys

Type, arrow, return. The same shape as the file menu that opens on @ in the composer, so it is one thing to learn rather than two.

The button's own wording carries the answer. on means your commits land on that branch; from means a fresh branch off it. One word, and it is on screen the whole time.

One thing we are not adding

a separate target branch

A target branch picker of its own

Conductor puts the merge target in a second control, defaulting to origin/main. Bloom ties the target to the source instead, and that is worth keeping. Cut a branch from a colleague's work and your pull request should land back on their branch, not on main. A separate target defaulting to main would fill that diff with commits you never wrote, which is the exact mess a review workspace exists to avoid.

The problem you hit was not the model. It was that the right route was buried in a menu with ninety branches above it, and nothing on screen afterwards said which of the two you had chosen. Both of those are fixed above.
